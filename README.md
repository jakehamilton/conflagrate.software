This repository contains the source for the website
[conflagrate.software](https://conflagrate.software). It also includes the
code for rendering a fire animation as well as a hand-crafted pixel art image
(which is low quality with my poor art ability), both of which are subject to
change as contributions are made.

## Development

To work on the website, you will need:

- This repository
- [NodeJS](https://nodejs.org)

Once you have the requirements listed above, you can install dependencies and
run the development server.

```shell
# Install dependencies
npm install

# Run the development server
npm run dev
```

## Build

To build for production, run the following command and serve the `dist/`
directory however you please.

```shell
npm run build
```
